Private Anwendungen

Diese Seite beschreibt kleine, private Anwendungen, mit denen ich meine eigenen Konten bei Drittanbietern auslese, zum Beispiel Schlaf- und Aktivitätsdaten meines Oura Rings und meines WHOOP-Armbands. Die Anwendungen sind nicht öffentlich. Es gibt keine Registrierung, keine Nutzerkonten und kein Angebot an Dritte.

Anwendungen

oura-mcp
Liest über die Oura API v2 (OAuth2) die Daten meines eigenen Oura-Kontos, nur lesend. Scopes: daily heartrate personal session spo2 workout stress heart_health tag.
whoop-mcp
Liest über die WHOOP API v2 (OAuth2) die Daten meines eigenen WHOOP-Kontos, nur lesend. Scopes: offline read:recovery read:cycles read:workout read:sleep read:profile read:body_measurement.

Wie dabei mit Daten umgegangen wird, steht in der Datenschutzerklärung. Die Bedingungen für die Nutzung stehen unter Nutzungsbedingungen.

Private applications

This site describes small private applications that I use to read data from my own accounts with third-party services, for example sleep and activity data from my Oura Ring and my WHOOP band. They are not public: there is no sign-up, no user accounts and no offering to third parties. See the privacy policy and the terms of service. Contact: apps@mgera.email.
